# Terminology sources

The Spanish print titles are local choices for the 32 quantitative observations in this starter dataset. Each printed title is associated with its LOINC code, official English long common name and observed UCUM unit in the release crosswalk. Use the code and specimen context when matching a short clinical label. [Crosswalk](terminology.csv)

We checked all 32 identifiers, official names and example units against the master table supplied with LOINC Complete 2.82. All 32 records were active in that release. The local aliases include HCM and CHCM for distinct erythrocyte measurements, percentages for the five differential fractions and total carbon dioxide for the chemistry measurement. The code for LDL cholesterol has no specified measurement method. [LOINC Complete 2.82](https://loinc.org/kb/release-notes-archive/2.82/) · [RDW-CV](https://loinc.org/788-0/) · [Total carbon dioxide](https://loinc.org/2028-9/)

The normalized labels come from the generator's original catalog names in LOINC Complete 2.82. English terms come from Regenstrief Institute and the LOINC Committee.
